# Short Course: Build a Website with Codex AI — No Coding Required


## Marketing
For students, beginners and small business owners who run small retail shops without scale in kenya, this course shows how to built websites with codex AI without programming knowledge so you can built your own website and scale your business to the world.


## Prerequisites

- Access to Codex AI in VS Code
- Internet connection
- Ability to type in the terminal

No programming knowledge required.

## Course Outline

| Lesson | Topic | Observable Learning Objective |
|---------|---------|---------|
| L1 | Introduction to Codex | Generate a one-page website from a written prompt. |
| L2 | Writing Effective Prompts | Add a heading, service description, and contact button using prompts. |
| L3 | Website Design | Apply a colour scheme, add at least one image, and create a navigation menu. |
| L4 | Testing and Improving | Identify and fix at least two issues in the website using Codex. |
| L5 | Business Website Project | Create and demonstrate a three-section business website with navigation and contact details. |
