# Lesson Objectives

## Vague Objectives (Not Measurable)

1. Understand NumPy.
2. Understand Machine Learning.

---

## Observable Objectives (Understand NumPy)

By the end of the lesson, you will be able to:

- Install NumPy.
- Import the NumPy library into a Python program.
- Create NumPy arrays from lists and tuples.
- Perform basic array operations such as addition, subtraction, multiplication, and division.
- Access and manipulate array elements using indexing and slicing.
- Apply common NumPy functions such as `sum()`, `mean()`, `max()`, and `min()`.
- Use NumPy arrays to perform simple data analysis tasks.

---

## Observable Objectives (Understand Machine Learning)

By the end of the lesson, you will be able to:

- Install Scikit-learn.
- Install and import NumPy.
- Load and prepare datasets for machine learning.
- Split datasets into training and testing sets.
- Train a simple machine learning model using Scikit-learn.
- Make predictions using a trained model.
