# writing clear explanations

## Before(Jargon-Heavy)
What is a database?
A database is an organized collection of related data that is stored and managed in a way that allows easy access, retrieval, updating, and manipulation.


## After (Plain english)
What is a database?

A database is a place where information is stored. You can add new information, find information, change information, or remove information when you no longer need it


## Analogy example
Think of a book where you record your exam results every term.

When you get new results, you write them in the book.
When you want to see your old results, you open the book and check them.
If you wrote something incorrectly, you can correct it.
If a page is no longer needed, you can remove it.

This record book works like a database because it stores information and helps you manage it easily.

## Question asked
Where can I find the database?

## Response
A database is usually found inside a computer, phone, or server, just like a record book is usually kept in a drawer, shelf, or your bag.
